About

실기기 기능 검증과 결함 재현 경험을 바탕으로, 사용자 관점에서 동작과 결과를 확인하는 QA입니다.

소개

한화비전 SQA에서는 AI 카메라의 객체 탐지 결과를 정탐·오탐·미탐 기준으로 확인하고, SQE에서는 NVR-CAM 호환성과 신규 모델 기능, 회귀 테스트를 수행했습니다. 실기기에서 기대 결과와 실제 동작을 비교하며, 결함 발생 시 환경·버전·설정 조건과 재현 절차를 정리해 PLM으로 공유했습니다. 변경 후 기존 기능을 다시 확인하고 테스트 조건과 결과를 문서화하는 과정을 중요하게 생각합니다.

강점

  • 환경·버전·설정 조건과 재현 절차를 정리하는 결함 리포팅
  • 실기기 기능 검증과 변경 후 기존 기능의 반복 확인
  • 기대 결과와 실제 결과를 비교한 판단, 검증 결과 문서화 및 공유

지향점

  • 사용자 흐름과 입력 오류 가능성을 고려한 테스트 범위 구체화
  • 문제 발견부터 요구사항 정리, 개선 결과 검수까지 QA 관점 확장
  • 반복 검증 항목의 체크리스트화 및 절차 표준화

자격증

  • 사무자동화산업기사
  • 유통관리사
